# comp-work

## Worker Ally prototype

The static NYC gig worker intake starts at the repository-root `index.html`; its vanilla CSS and JavaScript are in `worker-ally/`. It uses no build step or external service.

Open `index.html` directly in a browser, or publish the repository with GitHub Pages. The separate mock benefits-agent dashboard is `worker-ally/agent.html`.

Intake answers are stored only in this browser's local storage. Use **Start over** in the worker view to clear the saved demo profile. Agent follow-up actions and service recommendations are illustrative mock content; nothing is sent or submitted.
