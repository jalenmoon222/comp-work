# comp-work

## Worker Ally prototype

The static NYC gig worker intake prototype is in `worker-ally/`. It uses vanilla HTML, CSS, and JavaScript with no build step or external service.

Open `worker-ally/index.html` directly in a browser, or open it with VS Code Live Server. The separate mock benefits-agent dashboard is `worker-ally/agent.html`.

Intake answers are stored only in this browser's local storage. Use **Start over** in the worker view to clear the saved demo profile. Agent follow-up actions and service recommendations are illustrative mock content; nothing is sent or submitted.
